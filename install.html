DMG installation guide

Install LocalKeyRemapper on macOS.

Start with the DMG you already downloaded, move the app into Applications, approve its first launch and grant the Accessibility permission required for keyboard remapping.

macOS 13.5 or later No Terminal required Follow the steps in order
Start the guide Download options

Before you begin

This guide starts after the DMG has been downloaded.

If you do not have the DMG yet, use the Download page first. Only obtain LocalKeyRemapper from the official project distribution.

Part 1 · Install the app

Move LocalKeyRemapper into Applications.

These first steps are straightforward, so they stay text-only. The visual guide begins when macOS starts asking for security permissions.

  1. 1

    Open the disk image

    Open the downloaded LocalKeyRemapper DMG.

    Double-click the .dmg file in Downloads. macOS will mount it and open the LocalKeyRemapper installation window.

  2. 2

    Install

    Drag LocalKeyRemapper into Applications.

    In the DMG window, drag LocalKeyRemapper.app onto the Applications folder and wait for the copy to finish.

  3. 3

    Finish with the DMG

    Eject the LocalKeyRemapper disk image.

    After the copy has completed, eject the mounted disk image. The app remains installed in your Applications folder.

  4. 4

    First launch

    Open LocalKeyRemapper from Applications.

    Open Finder → Applications, then double-click LocalKeyRemapper.app.

Part 2 · Allow the first launch

Approve LocalKeyRemapper in macOS Privacy & Security.

  1. 5

    Security warning

    When macOS blocks the app, click Done.

    The first warning says Apple could not verify the app. Do not choose Move to Trash. Click Done to close the warning.

  2. 6

    Privacy & Security

    Open System Settings and click Open Anyway.

    Go to System Settings → Privacy & Security, scroll down to the Security section and find the LocalKeyRemapper message. Click Open Anyway.

    System Settings → Privacy & Security → Security → Open Anyway
  3. 7

    Confirm opening

    Confirm Open Anyway, then authenticate.

    macOS asks once more whether you want to open LocalKeyRemapper. Click Open Anyway. Then approve the action with Touch ID or enter an administrator password if requested.

Part 3 · Grant Accessibility permission

Allow LocalKeyRemapper to remap keyboard events.

Opening the app and granting Accessibility access are separate macOS protections. The app can open before it has permission to remap keys.

  1. 8

    Open Accessibility

    Click Open Accessibility Settings… in LocalKeyRemapper.

    After the app opens, LocalKeyRemapper shows Accessibility Permission Required. Click Open Accessibility Settings….

    If you do not see the button, you can open the same page manually: System Settings → Privacy & Security → Accessibility.

  2. 9

    Add LocalKeyRemapper

    Click +, select LocalKeyRemapper.app, then click Open.

    In Accessibility settings, click the + button. Select LocalKeyRemapper.app from Applications and click Open.

    If LocalKeyRemapper is already listed, you can skip the + step and continue directly to the next step.

  3. 10

    Enable permission

    Turn on the switch next to LocalKeyRemapper.

    LocalKeyRemapper now appears in the Accessibility list. Enable the switch next to it. Authenticate again if macOS asks.

Part 4 · Finish

Turn on keyboard remapping.

  1. 11

    Ready

    Return to LocalKeyRemapper and enable Keyboard remapping.

    Return to the LocalKeyRemapper window and turn on Keyboard remapping. Your saved active profile can now remap keys locally on your Mac.

Why two approvals?

Opening the app and remapping keys are separate macOS protections.

01

Open Anyway

Allows macOS to open this copy of LocalKeyRemapper after you explicitly approve it.

02

Accessibility

Allows LocalKeyRemapper to interact with protected keyboard events so your configured remapping rules can work.

Done

LocalKeyRemapper is ready.

You can now create profiles, configure rules and enable or disable remapping whenever you need it.
