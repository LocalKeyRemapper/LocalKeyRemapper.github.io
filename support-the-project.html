Support the project

Help keep LocalKeyRemapper
free and open source.

LocalKeyRemapper is developed and distributed as a free, open-source macOS application. If you find it useful, you can support its continued development, maintenance and distribution.

♡ Support on GitHub View source code

Sponsorship is completely optional. LocalKeyRemapper remains free and open source regardless of whether you sponsor the project.

What your support helps fund

Support goes back into the project.

Sponsorships help cover the practical costs of maintaining and improving LocalKeyRemapper while keeping the application freely available to everyone.

01

Development

Continued work on new features, refinements, bug fixes and long-term improvements.

02

Maintenance

Keeping LocalKeyRemapper working reliably as macOS evolves and the project grows.

03

Distribution

Supporting the costs associated with distributing future releases to macOS users.

04

Signing & notarization

Helping fund the Apple Developer Program so future releases can be properly signed and notarized.

Current priority

A smoother installation experience on macOS.

One of the project's current funding priorities is covering the Apple Developer Program membership required for signed and notarized releases.

This would reduce the additional first-launch security steps currently required for an independently distributed, non-notarized build.
