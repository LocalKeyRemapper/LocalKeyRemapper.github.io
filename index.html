Designed around four principles

Focused on what matters before adding anything else.

Keyboard remapping works close to one of your most personal input devices. LocalKeyRemapper is therefore designed around accessibility, privacy, security and native performance from the beginning.

01

Accessibility first

Adapt key positions and combinations to individual motor needs, reduced-movement workflows, one-handed use or personal comfort.

02

Privacy first

Configuration and remapping remain local. The app has no accounts, cloud services, telemetry, analytics or keystroke history.

03

Security first

A narrow feature set, public source code, App Sandbox and protected macOS permissions make the app easier to understand and review.

04

Native performance

Built specifically for macOS with native technologies, no browser runtime and no network dependency in the remapping path.

One focused responsibility

A keyboard remapper, not a collection of unrelated utilities.

LocalKeyRemapper takes inspiration from the keyboard-remapping concept in Microsoft PowerToys, but follows a much more focused approach: instead of bundling many unrelated utilities, it is built specifically to make keyboard remapping on macOS deeper, clearer and more capable.

That vertical focus makes room for profiles, per-profile shortcuts, precise modifier behaviour, bidirectional rules, exceptions and native macOS integration while keeping configuration and remapping local — with no accounts, telemetry, analytics, cloud services or remote processing.

Accessibility first

The keyboard should adapt to the person using it.

Moving a frequently used key, avoiding an uncomfortable combination or reducing repeated movement can make a meaningful difference. Accessibility is not an optional mode in LocalKeyRemapper; it is part of the core design.

The app is intended to complement the mature accessibility foundation already integrated into macOS, including workflows that use Sticky Keys.

Reduce difficult movement

Move frequently used inputs closer to an easier or more comfortable area.

Support one-handed workflows

Create a dedicated layout around the keys that are easiest to reach.

Replace unavailable keys

Temporarily remap around a damaged, unreliable or inaccessible key.

Switch with your setup

Keep separate profiles for different keyboards, positions or tasks.

Local by design

Keyboard ↓ Processed locally on your Mac ↓ Remapped input

No cloud step. No account. No remote processing.

Privacy and security

Nothing needs to leave your Mac.

LocalKeyRemapper does not require an Internet connection and does not send keyboard activity, profile data or usage analytics to a remote service.

The complete Swift source code is public, so users and security reviewers can inspect the implementation or build the application independently.
